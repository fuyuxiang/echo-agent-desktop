## 产品与架构

- **工作项统一**：旧计划迁入任务数据，保留 `legacyPlans`；列表、看板共用状态，删除重复计划写入 API。Agent 本轮结束与人工验收分开，验收须确认。
- **入口与来源**：侧栏使用“能力”“定时任务”；能力页连通专家／技能／连接器与插件市场；知识资料与个人记忆提供一致的切换入口。首次使用区分无连接与已有连接未就绪，不再要求所有用户填写 API Key。
- **降级解释**：组织知识跳过会显示本轮未使用的来源及详情入口。验证环境缺失与代码失败使用不同状态。
- **备份恢复**：有版本的 ZIP、逐文件 SHA-256、范围预览、文件数／大小边界、路径与别名冲突检查；临时目录校验；原生启动前应用恢复；日志回滚；界面状态先于 store 初始化恢复。恢复后的定时任务、代码执行、队列均暂停；旧在途调度记录结束为失败，避免重放。
- **备份范围**：会话、项目元数据与应用管理的项目资料、代码任务、记忆、会议、粘贴附件、草稿、队列、成果目录、本机用量、主题。排除模型配置、组织凭据及外部工作目录原文件。外部文件引用仍依赖原路径；被替换的数据保留在 `restore-previous-*`。
- **维护边界**：进程监督、资源身份、备份、界面持久化形成独立模块；新增文件有明确失败处理。记忆 DTO 使用真实序列化断言；备份前后端白名单有合约检查。原有大模块按本轮完整流程提取，未一次性重写。
- **渲染与样式**：历史消息 memo；时间线按消息变化计算；稳定主题 Context；代码工作台样式随功能加载；新增导航样式单独维护。
- **实验能力**：未接入产品的 Sandbox、Docker、OIDC 原型移至 `src/experimental`，更正“安装即自动激活”的注释；测试禁止生产入口引用实验适配器。

## 仍需真实部署环境验证的边界

- 本机环境为 macOS Intel。Windows 运行与安装结果必须由新增 Windows CI／实机产生，不能用平台分支单测代替实机结果。
- 内置服务的 HTTPS 终止点属于服务端部署，本仓库无法创建可用 HTTPS 服务。本轮采用默认本机检索与远端显式确认；可配置可信 HTTPS 服务。
- 真实模型、组织服务、会议转写、通知外发、签名更新安装依赖对应账号／服务和发行环境。本轮未把模拟或无模型调用的测试算作这些服务验收。
- Provider API Key 的既有本机配置存储边界仍在 README 明示，备份排除该配置；组织凭据继续使用原有系统保护机制。完整个人凭据迁移、全量 IPC 生成、所有应用服务／数据库迁移属于后续架构演进，不能把本轮局部模块化描述为已经完成全仓迁移。
