# 内置天气与联网搜索

在普通对话中输入“北京明天天气怎样”或“搜索最近的某项公告”，Agent 可按需调用内置的只读工具。新会话和恢复的会话都会自动连接；用户无需安装 Skill、配置 MCP、填写天气密钥或指定搜索模型 ID。

- 天气使用 `wttr.in` 的 JSON 预报，服务不可用时尝试 `wttr.is`。结果包括匹配的地点、当前状况、未来三天的温度和逐时降雨信息。
- 搜索优先读取 Bing 的公开 RSS 搜索结果，失败时尝试 DuckDuckGo 网页搜索。结果包含标题、链接、摘要和获取时间；Agent 应引用来源链接，并核实重要结论。
- 天气地点和搜索词会发送到对应的外部服务。功能需要网络连接，公开服务可能限流或临时不可用；这时工具会明确返回错误，不应编造实时结果。
- 对话中的工具调用仍可查看。设置页不提供天气或默认搜索开关；原有 `[models].web_search` 配置继续供需要模型原生搜索的用户使用。
