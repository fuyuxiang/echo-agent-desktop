# 微信远程对话

微信 Bot 是桌面 Agent 的远程入口，使用同一份会话记录和任务权限。桌面应用运行时，原生后台会保持微信消息轮询；关闭应用后不会执行微信指令，重新打开后会从已保存的游标继续拉取。

## 开始使用

1. 打开“设置 → 通知 → 微信远程对话”，获取二维码，并用手机微信扫码确认。如微信要求配对码，在设置页输入。
2. 在已有任务的右键菜单或顶部“更多操作”里选“在微信继续”。该任务立即成为微信的当前会话。首次交接后，先在微信向 Bot 发送“状态”，建立聊天上下文。
3. 直接发送消息即可接续该任务。桌面和微信的消息进入同一会话。
4. 若需在微信浏览更多已有任务，在设置页勾选允许访问的工作区。仅这些工作区的任务会出现在微信“任务”列表；单独交接的任务也可访问。

## 微信指令

| 指令 | 作用 |
| --- | --- |
| `任务`、`任务 2` | 分页列出已授权的已有会话及当前会话 |
| `切换 #编号` | 切换当前会话，编号取自“任务”列表 |
| `工作区` | 查看新任务可用的已授权目录 |
| `状态` | 查看当前会话状态 |
| `停止` | 请求停止当前会话的执行 |
| `新任务：内容`、`新任务 2：内容` | 在默认或指定编号的工作区创建并运行任务 |
| `/文件 相对路径` | 将当前会话工作区内不超过 20 MB 的普通文件发送到微信 |
| `帮助` | 查看微信指令 |

引用 Bot 的某条会话回复时，会优先回到该回复对应的会话。普通文字会进入当前会话。支持语音消息中微信提供的转写文本、图片和常见文档；不支持的消息类型会收到说明。

权限请求、Agent 提问和方案确认会发到微信，并带独立编号。按消息中的指令回复即可处理。内容过长、无法在微信完整展示的请求需要在桌面审阅和批准；微信仍可拒绝。会话沿用桌面设置的权限模式。

## 安全边界

绑定凭据保存在本机受保护的凭据存储中，工作区授权和消息游标保存在本机私有配置文件中。微信仅接受绑定账号的单聊指令，不执行群聊消息。接收的文件先经过大小、类型和下载域名检查；`/文件` 仅能读取当前工作区内的普通文件。解除绑定会停止轮询并删除本机凭据。

## 维护与验证

通道使用腾讯 iLink Bot 协议的 2.4.9 版本字段，接口与媒体格式参照 [Tencent/openclaw-weixin](https://github.com/Tencent/openclaw-weixin)。实现位于 `src-tauri/src/weixin.rs`，不依赖 OpenClaw 运行时。

发布前需用真实微信账号完成：扫码和配对码、已有会话交接、微信内切换和引用回复、文字/图片/文档收发、权限和方案确认、长任务回报、网络断开后的恢复及解除绑定。自动化检查无法代替手机微信侧的授权与实际消息投递验证。
